# theroadtohana.github.io

Personal research portfolio for Hana, a researcher in social and affective science (interoception, empathy, romantic love, interpersonal physiology).

Built with plain HTML and CSS and hosted on GitHub Pages. Live at **https://theroadtohana.github.io**.

## Files

- `index.html` – all page content
- `css/styles.css` – colors, fonts, layout (change the colors at the top to re-theme)
- `assets/` – CV, profile photo, and creative-work images

## Editing

Open `index.html` on GitHub, click the pencil icon, edit, and commit. The site updates in about a minute.
